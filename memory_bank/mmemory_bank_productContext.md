# Memory Bank · Product Context
**Why this exists:** Developers waste time on “shiny‑object” features lacking user proof. Qualitative feedback is scattered across docs and chat.

## Problems Solved
* Evidence is hard to find at idea stage.
* Personas are often ignored after initial research.
* PMs manually compile data, causing delays.

## User Experience Goals
* One‑click Evidence Score for any PRD.
* Chat with a persona bot directly inside the code editor.
* Visual tray badge when evidence is insufficient.
